# ADR-030

标题：V1 Pilot 只验证可靠性；有监督可进档口，不宣称无人值守

- 状态：proposed
- 日期：2026-08-17

## 背景

P0（PR40）已证明一分钟开单闭环。下一步容易做成继续加功能，或把 Demo 金脚本当成已经可以全天听懂档口话。

清单：[V1_SALES_CLERK_PILOT_CHECKLIST.md](../V1_SALES_CLERK_PILOT_CHECKLIST.md)。服从 [RUNTIME_FREEZE.md](../RUNTIME_FREEZE.md)。

## 问题

Sales Employee V1 能否进入真实档口测试？Pilot 成功看什么？

## 决策

1. 本阶段 **不加功能**。不改 Runtime、Confirm Gate、不新增 Agent、不引入库存/支付/财务、不扩展 ERP。
2. Pilot 先过五项使用前检查：当前单明确、确认前可改、确认后拒绝、今日本一致、Outbox 可靠。
3. 异常必须演：同名必问（种子用两个王老板）、无档案苹果挂起、换客不串单、网络失败状态清楚、ERP 失败则已确认但入账异常。
4. Demo 金脚本只验证体验；真实模式走完整 Runtime，关闭口令映射。
5. 成功标准：少手写、少重复确认、少翻聊天找单。
6. **可以进入有监督的档口 Pilot。不可以宣称无人值守已可雇。**

## 原因

不可靠的聪明比少功能更危险。闸门已经在；试班是把闸门对准真实嘴，不是再做一个员工。

## 影响

- 好处：进摊标准可执行；Demo 与真实模式不混。
- 限制：试班要有人提醒换页、答档口；不做收款库存。
