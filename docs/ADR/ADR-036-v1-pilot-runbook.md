# ADR-036

标题：V1 第一档口按执行手册跑；陪跑可提醒不可代开；结束只看老板习惯

- 状态：proposed
- 日期：2026-08-17

## 背景

接入、观察、反馈已齐。若没有当天怎么跑的手册，陪跑人会代喊代点，或用功能多少判断成败。

手册：[V1_SALES_CLERK_PILOT_RUNBOOK.md](../V1_SALES_CLERK_PILOT_RUNBOOK.md)。服从 [ADR-030](ADR-030-v1-pilot-hardening.md)、[ADR-034](ADR-034-v1-pilot-onboarding.md)、[ADR-035](ADR-035-v1-pilot-feedback-loop.md)、[RUNTIME_FREEZE.md](../RUNTIME_FREEZE.md)。

## 问题

第一个真实档口 Pilot 当天如何执行？人工何时介入、何时必须停 AI？结束如何判断？

## 决策

1. 本阶段 **不开发新功能**。不改 Runtime / Confirm Gate，不新增 Agent，不引入库存/支付/财务。
2. 开跑前：企业事实切片、设备、网络、负责人；V1 不要求老板登录账号。
3. 第一天只记开门 / 第一单 / 高峰 / 收摊，观察老板是否主动使用。
4. 陪跑可提醒换页、答档口、解释状态；不可代选客、代点好了。串单、猜同名、确认后改、用钱货挡确认、页面不可用、老板说停 → **必须停 AI**，改手写。
5. 每日复盘固定四问，第 4 问与反馈闭环同一句：明天还会用吗。
6. 结束只选 **继续扩大 / 继续观察 / 暂停**。根据老板习惯，不根据功能数量。

## 原因

执行手册把「有监督可进档口」落成当天动作。停 AI 是保生意，不是当场改闸门。

## 影响

- 好处：第一档口可跑；陪跑边界清楚；结束三选一。
- 限制：必须有陪跑人；无切片、无设备不去摊。
