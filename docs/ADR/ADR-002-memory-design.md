# ADR-002

标题：Memory 不是聊天历史

- 状态：accepted
- 日期：2026-08-16

## 背景

农批开单会连续语音、改口、缺价。若把全部对话当长期记忆，会把「60 件」「不对」「好了」当成客户知识，并让 RAG 扫聊天表。

## 问题

跨会话要记住什么？什么必须丢掉？

## 决策

Memory 必须：

```
Extract → Policy 审核 → Storage
```

保存：

- 客户别名
- 商品习惯（如档案默认 SKU，达阈值才写）
- 价格规则（带有效期的 quote / deal / special / 当日行情）
- 长期业务事实

禁止保存：

- 全部聊天
- 临时数量
- 一次性口误
- `price_tbd`、未解析提及、整句 `user_text`

`session_turns` 仅审计，记忆检索禁止扫描该表。

## 原因

聊天是过程，记忆是稳定事实。价格有时效，数量是当笔订单，口误不是偏好。Extractor 默认空输出；LLM 只建议，闸门否决则不写。

## 影响

- 好处：熟客缺槽可回填且可过期、可撤销。
- 限制：第一阶段不会「越聊越懂」到记住每次 60 件；习惯类写入有阈值。
