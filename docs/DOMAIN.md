# 农批业务知识

供实现与 Policy 使用的行业事实。与代码冲突时以 `docs/DESIGN.md` 为准；本文解释「为什么农批这样说、这样开单」。

## 客户

- **同名客户**：市场里可以有多个「王老板」。称呼不是唯一键。消歧靠档口、手机尾号、最近成交，禁止静默选最近一个。
- **档口**：摊位号是现场识别主线索（「3 号档那个王老板」）。
- **联系方式**：电话用于复述和以后 ERP Customer，第一阶段不登录验证。
- **信用**：现结 / 挂账只归档，不做额度引擎；不得因信用未知而拒绝开单。
- **价格关系**：熟客可能有特价或「老价格」；未绑客户不得套任何人的价或默认货。

## 商品

必须支持本体树，口语可打在任意层：

```text
category    水果
    ↓
variety     苹果
    ↓
cultivar    红富士
    ↓
sku         红富士 80 果一级烟台箱装
```

只有 sku 可履约、可挂价、可进 ERP。老板说「苹果」往往停在 variety；说「金边榴莲」往往是 cultivar。「八零果」是规格口语，不是独立品类。

禁止自动替品（没金边改金枕）。过季货不得当静默默认。

## 价格

价格不是商品上的一个死数字，依赖：

- **客户**（特价 / 熟客档）
- **商品**（必须落到 sku 才能记成交价）
- **时间**（行情日变，记忆必须过期）
- **数量**（大批发可能议价；第一阶段不自动按量改价）
- **历史成交**（「老价格」）；POC **默认不静默**套上周成交，避免行情已变

开单单位（件 / 个）与计价单位（斤）经常不一致。无件重换算因子时禁止估算。缺价不打断开量；确认时可 `price_tbd`，不得把 TBD 说成已成交。

## 语言习惯

| 口语 | 含义 |
| --- | --- |
| 老王 / 王老板 | 客户别名，可能同名 |
| 八零果 / 80# / 八十果 | 规格，用于 refine_spec |
| 老价格 | 指向价格记忆，不是新报价 |
| 那个苹果 | 指代 focus 行或最近苹果行 |
| 不对 / 改成 | 改口，打在上一行或点名行 |
| 加 / 再来 | 累加，不是覆盖 |
| 好了 | 确认本单任务，不是闲聊结束 |
| 件 / 个 / 箱 / 斤 | 单位；未说则用节点 default_uom |

连报时老板不会等系统问完规格再报下一品。系统必须先收下能落的行，歧义挂起，idle 或「好了」再问。
